# 827829 — AB Club 微信小程序基础仓库

仓库标识：`heikesong`

这是 AB Club 原生微信小程序的一期本地实现。产品主轴是面向全球华人的高端数字名片：填写资料、实时预览、安全分享与克制的人脉关系记录；全球活动、艺术内容和所在城市群只保留轻量入口。共享合同、模块边界、集合所有权与证据状态仍保持受控。

## 一期界面与功能基准

- 冷启动直接进入 AB Club 品牌「发现」页，不要求用户先注册或初始化身份。
- 主导航为 `发现 / 活动 / 名片 / 我的`；「发现」位于最左，人脉总页只从发现页的低权重二级入口进入。
- 视觉统一使用象牙白、墨黑、香槟金和暖石灰灰，复用 AB Club 金色盾徽。
- 名片审核不是创建、预览或分享的前置条件；敏感字段仍按隐私范围展示。
- 发现页不直接展示完整个人名片，只提供创建与查看名片入口，并保留少量“值得认识”、策展活动、艺术/古董/珠宝及 7 国 13 城内容。
- 活动作为独立一级页展示本地高清策展预览；一期不提供报名、支付或真实排期承诺。
- “我的”按名片所在城市显示 7 国 13 城中的对应城市群；当前申请入口不会伪造已提交或已加入状态。
- 一期不提供公开群二维码、站内聊天、动态流、点赞、粉丝、活动报名、支付、商家入驻或交易。
- 当前冻结合同只允许保存姓名、城市、简介与已有头像资源 ID；教育、职业、兴趣和逐字段可见性仍是界面预览，待共享合同扩展后才能接入真实保存，不能把预览状态当作已落库。
- “人脉关系记录”当前只展示双方已接受的关系，不等同于“谁看过我的名片”或名片交换流水；冻结合同尚未提供浏览/交换事件，因此一期客户端不会伪造该历史。

## 下载后在微信开发者工具运行

1. 克隆或下载本仓库，保持 `project.config.json` 在项目根目录。
2. 在微信开发者工具选择“导入项目”，目录指向仓库根目录。
3. 使用自己的 AppID，或在开发者工具允许时选择测试号；仓库不会携带维护者的本机 AppID。
4. 点击“编译”。默认直接进入「发现」，不依赖 CloudBase，可完整查看 `OFFLINE_DEMO` 品牌、活动、名片与分享界面。
5. 若要执行仓库自动化验证，再安装 Node.js `>=24.0.0`，运行下方命令。

## 自动化验证

本仓库的验证脚本要求 Node.js `>=24.0.0`；这是为了使用稳定名称的单进程测试隔离开关，并让受限环境中的测试不依赖派生子进程。客户端 TypeScript 运行时测试由锁定版本的 `tsc` 编译到被忽略的 `.tmp/test-runtime/`，不依赖 Node 的实验性 TypeScript API。

```powershell
npm ci
npm run build
```

`npm run build` 依次执行小程序与云端 TypeScript 检查、合同/路由/manifest 校验、Node 测试和静态包体预算检查。自动化结果不能替代微信开发者工具的权威编译、预览、体验版上传或真机验证；这些证据会在实际完成后单独记录。当前界面不引用第三方运行时组件，因此下载者无需先“构建 npm”即可打开默认 `OFFLINE_DEMO`。

云函数以 `.ts` 为唯一实现源；提交的 `.js` 是 `npm run build:cloud-runtime` 生成的自包含 CommonJS bundle。`npm run build` 会校验 bundle 内的源文件 SHA-256，防止类型检查的源码与实际执行文件漂移。修改 `cloudfunctions/**/*.ts` 或云端使用的共享合同时，必须先重新生成 bundle。
