# AB Club 活动入口与全球艺术日历改版计划

## 范围

本次把用户给出的两段要求合并为一条清晰的产品路径：

1. `pages/events/index` 作为「活动」一级页面，只保留三个双语品牌入口：
   - `GLOBAL ART CALENDAR / 全球艺术日历`
   - `SPIRIT PEARLS / 灵气珍珠`
   - `PUBLIC GOOD / 公益`
2. `packageEvents/pages/calendar/index` 作为「全球艺术日历」二级页面，承载 2026 年已给出的艺术与文化节点。
3. 珍珠与公益入口先保留点击反馈，不创建二级页面、不虚构 SKU、价格、项目或日期。
4. 现有其它活动详情、城市目录和艺术资料路由保留，避免破坏旧链接；它们不再从新的活动一级页直接展开。

## 视觉与交互

- 深色墨黑画布、暖金细线、象牙白文字，使用 Georgia 与系统宋体衬线栈。
- 一级页采用三段纵向入口与细线编号，避免资讯流和商城卡片。
- 二级页采用 `2026 → 月份 → 城市 → 事件` 的纵向时间轴；重点事件使用更大字号、金色标记和更宽留白。
- 月份导航使用横向滚动按钮，点击后通过 `scroll-into-view` 跳转到对应月份。
- 所有触点至少 `var(--ab-touch-target)`，为窄屏、暗色模式、减少动画和长文案提供降级。

## 数据边界

- 日历只使用需求中列出的 2026 日期，原样保留日期和城市，不推测其它日期。
- 没有活动的月份仍显示月份锚点，但只显示“本期未收录已确认节点”，不写“日期待定”。
- 不新增报名、支付、票务、价格、商品 SKU 或好友关系能力。

## 验收标准

- 一级页 DOM 只出现三个入口，三项均含中英文标题；全球艺术日历可进入日历二级页。
- 二级页注册为 `packageEvents/pages/calendar/index`，包含 JAN、FEB、MAR、MAY、JUN、SEP、OCT、DEC 的给定事件及其它月份锚点。
- 重点事件与普通事件存在可验证的视觉层级差异；月份导航可触发滚动定位。
- 通过 `npm run typecheck`、`npm run validate`、`npm test`、`npm run check:package` 和微信开发者工具构建验证。
