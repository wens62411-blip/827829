# Community visual asset

`european-salon-hero.jpg` is the local, package-managed hero used by the
community contact panel on `pages/me/index`.

- Source: [Tremezzo Villa Carlotta (interior) (25).jpg](https://commons.wikimedia.org/wiki/File:Tremezzo_Villa_Carlotta_(interior)_(25).jpg)
- Author: Pierre André Leclercq
- License: CC BY-SA 4.0
- Original file recorded by Wikimedia Commons: 4896×3672. The processing
  input was Wikimedia's 3840×2880 derivative from that source page.
- Runtime derivative: center-focused crop from 3840×2880 to a 3420×1425
  source region at `(420, 500)`, then high-quality bicubic resize to 1440×600
  and JPEG encoding at quality 76.
- Runtime size: 90,898 bytes

The local file is used instead of an external hotlink. Source and license
metadata are recorded in `../manifests/community.json`; public-use rights
remain subject to the recorded human review gate.
