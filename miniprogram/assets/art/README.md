# Art fallback asset

`not-real-artwork-fallback.svg` is an AB Club project-owned abstract placeholder.
It depicts no real artwork, antique, jewellery item or pearl, and must never be
presented as catalogue imagery or authenticity evidence.

Use it only when a public image is unavailable, lacks a sufficient rights basis,
or fails to load. The machine-readable rights and integrity record is
`../manifests/art.json`.
